# Contributing to Awesome Financial Crime

Thank you for your interest in contributing to Awesome Financial Crime!

We welcome high-quality resources related to financial crime compliance, AML/CFT, fraud detection, sanctions, market abuse, investigations and supporting data science and engineering tools.

## What to Contribute

Contributions may include:

- Open-source tools, libraries, datasets and research projects.
- Commercial financial crime compliance platforms.
- Regulatory guidance, industry standards and official resources.
- Educational materials, books, courses and podcasts.
- Practical tools supporting financial crime investigations and analytics.

## Resource Selection Criteria

Please ensure that your proposed resource:

1. Is relevant to financial crime compliance or a clearly related technical discipline.
2. Provides practical, educational, regulatory or research value.
3. Has a working, preferably official, website or repository link.
4. Is not already listed, unless the contribution provides a meaningful improvement.
5. Has a concise, factual and vendor-neutral description.

Commercial products are welcome, but promotional language, unsupported performance claims, referral links and affiliate links are not accepted.

Inclusion does not imply endorsement.

## How to Contribute

1. Check the existing README to avoid duplicates.
2. Fork the repository and create a branch for your changes.
3. Add the resource to the most appropriate existing section.
4. Follow the existing Markdown formatting and badge conventions.
5. Submit a pull request explaining the resource's relevance and your changes.

For new sections or substantial restructuring, please open an issue first to discuss the proposal.

## Formatting Guidelines

- Use the existing resource entry style: `Resource Name - Brief description`.
- Keep descriptions concise and objective.
- Prefer official websites and canonical GitHub repositories.
- Preserve the existing section structure and Table of Contents.
- Use the established blue Website and green Code badges.
- Avoid unnecessary changes to unrelated content.

## Review Process

Pull requests are reviewed for relevance, accuracy, link quality, duplication and consistency with the repository's scope.

Maintainers may request changes or decline submissions that do not meet the curation criteria.

All contributions are appreciated, but acceptance is not guaranteed.

## Code of Conduct

Please communicate respectfully and constructively. Disagreements about resource relevance or quality should focus on evidence and technical merit.

Thank you for helping make this resource collection more useful to the financial crime community!
